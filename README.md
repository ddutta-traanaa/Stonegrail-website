# Stone Grail Website

Corporate website for Stone Grail Technologies Private Limited.

## Files
- `index.html` — main site
- `terms.html` — Terms & Conditions and Disclaimer
- `styles.css` — shared styles
- `script.js` — interactivity
- `logo.png` — company logo

## Hosting
Deployed via GitHub Pages. To enable: Settings → Pages → Source: `main` branch, `/ (root)`.

## Custom domain
Add a `CNAME` file at the repo root containing your domain (e.g. `www.stonegrail.com`) and configure DNS at your registrar.
